# VeteranSudoku-PrivacyPolicy
## App update policy

`update-policy.json` is served by GitHub Pages beside the privacy policy.
For each platform, keep `releases` ordered oldest to newest and append only
versions already available in its store. Use major.minor.patch marketing
versions, not build numbers. Set `required` to true to require older installs
to update. With false, updates are optional unless the player is two or more
published releases behind, in which case the app requires an update.

Configure the Android store URL in the app before publishing Android updates.
